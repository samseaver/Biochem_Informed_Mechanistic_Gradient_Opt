# Runtime environment for generate_feasible_flux.py and predict_bioinformed_flux.py
#
# Tested in micromamba env: bf-runtime
# Python: 3.11
#
# Build from scratch:
#
#   micromamba create -y -n bf-runtime -c conda-forge python=3.11 glpk
#   micromamba run -n bf-runtime pip install -r requirements-runtime.txt
#
# Note on keras versions: scikeras pulls keras 3.x, which pip warns conflicts
# with tensorflow 2.15's required keras 2.x. The imports run fine despite the
# warning and the published sweep completed with this combination.

# --- ModelSEED dependencies, installed from source -------------------------
# Neither is on PyPI. Both are pinned to a commit rather than a branch so the
# environment is reproducible: a branch would move under you.
#
# cobrakbase needs the cobra-model branch, not master -- master lacks the
# KBase-model support this uses. The pin below is Fxe/cobrakbase, the upstream
# repository; it is byte-identical to the samseaver fork the published sweep
# was run against (that fork's one extra commit is an empty merge).

cobrakbase @ git+https://github.com/Fxe/cobrakbase.git@42075fbfdadaf9d32a5f1493d7b68e705f99c0f8

# --- Data dependencies, not installable ------------------------------------
# The figure scripts (Paper_Figures/) additionally need two sibling
# repositories. Neither is a Python package, so neither can be pip-installed;
# clone them and set the env var, or place them beside this repository under
# the default names below.
#
#   ModelSEED/PlantSEED @ tag v2.5 (commit 212b817)
#     git clone --branch v2.5 https://github.com/ModelSEED/PlantSEED
#     BIOFLUX_PLANTSEED_DIR=<checkout root>     default: ../PlantSEED
#     supplies Data/PlantSEED_v3/PlantSEED_Roles.json (reaction -> subsystem).
#     The file is under PlantSEED_v3/ even at tag v2.5; both dirs exist there.
#
#   samseaver/RNASeq_Enzyme_Abundance @ tag bioflux-preprint-260813
#     BIOFLUX_RNASEQ_DIR=<checkout>/projects/qpsi-plastidial
#     default: ../RNASeq_Enzyme_Abundance/projects/qpsi-plastidial
#     supplies {Poplar,Sorghum}_reaction_molar_fractions.tsv (gene -> reaction)
#     and rnaseq-data/{Poplar,Sorghum}_raw_genes_tmm_mean.tsv[.xz].
#
# Neither is needed to run the solver -- only to regenerate the figures.
#
# The measured phenotype data (ICP-MS + reflectance) is not a dependency:
# it ships with this repository at data/phenotype/.
